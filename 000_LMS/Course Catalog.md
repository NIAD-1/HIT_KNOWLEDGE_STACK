## Suggested First Personal LMS Path

This is a practical path because it connects domain knowledge, software building, data systems, and founder thinking.

| Week | Focus | Output |
|---|---|---|
| 1 | Personal LMS architecture | Obsidian dashboard and progress model |
| 2 | Next.js basics | Local prototype for browsing learning units |
| 3 | Markdown parsing | Script that indexes courses and topics |
| 4 | Database design | Schema for progress, units, projects, reviews |
| 5 | Search | Full-text search across vault notes |
| 6 | RAG fundamentals | AI tutor over selected notes |
| 7 | Regulatory science path | Curated regulatory-intelligence track |
| 8 | Assignment engine | Turn `Assignment.md` into proof-of-work tasks |
| 9 | Review system | Weekly review and spaced repetition |
| 10 | Product layer | Founder-thinking and POEM templates |
| 11 | Capstone | Build a small local LMS prototype |
| 12 | Reflection | Decide whether to expand, simplify, or productize |
