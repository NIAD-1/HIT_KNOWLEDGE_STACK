# The Philosophy

LMS home: [[000_LMS/LMS Home]]

Traditional education teaches subjects.

Founders need to master **systems**.

Every topic we study will answer four questions:

1. What is it?
2. How does it work?
3. Why does it exist?
4. How can I build a billion-dollar company using it?
